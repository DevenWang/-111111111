自己没有高德，所以只能自己抢一个。
**第 1 步｜电脑侧**

- 那台电脑上**以管理员身份**运行 exe（要加载 WinDivert 驱动）
- 开热点，点「开始广播」
- 确认日志出现 `[HTTP] 监听 0.0.0.0:80` 和 `[HTTPS] 监听 0.0.0.0:443`
- 防火墙弹窗选 "允许"（专用 + 公用都要勾）

**第 2 步｜新车连热点**

- 车机连这台电脑的热点，**不要改 DNS**，网关自动就是这台电脑的 IP

**第 3 步｜新车装证书（这步最容易漏）**

- 车机浏览器打开 `http://<那台电脑的热点IP>:8898/`
- 下载 `ca.crt` 并安装（位置：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书）
- 装完确认证书列表里能看到这张新证书

**第 4 步｜先刷商店首页，再下载**

- 打开应用商店，**停在首页刷新一次**（这一步才会调 `sdkInit`）
- 回电脑看日志，必须出现：
```
[会话] plainText=<新车设备号>
```

且这个号**不是** `P3000123049xxxxxxxxxxx`（那是旧车的）
- 确认日志里出现新车的 IP（`192.168.137.x`，不一定还是 .187）

**第 5 步｜下载安装**

- 这时再点下载。日志会打印 `DES下发 <包名>`，等它走完，车机就会自动安装

## 为什么顺序不能反

加密密钥 = 设备号前 8 字节。程序只在捕获到 `sdkInit` 时才更新设备号：

- 先刷首页 → 拿到新车设备号 → 按新车 key 加密 → 车机解得开 ✅
- 直接点下载 → 程序还用旧车设备号加密 → 新车用自己的号解密 → 对不上 → 卡 100% ❌

如果第 4 步日志里始终不出现 `plainText`，那就是 sdkInit 没被劫持到，回头查证书（第 3 步）和防火墙。
